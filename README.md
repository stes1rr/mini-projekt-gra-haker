# Mini-projekt: gra Haker

Prosta gra tekstowa napisana w Pythonie. Gracz próbuje złamać kody w fikcyjnej sieci, zdobywając punkty i unikając alarmu.

Gra działa lokalnie i nie łączy się z prawdziwymi urządzeniami ani sieciami.

## Uruchamianie

```bash
python breach.py
```

Wpisz `help`, aby zobaczyć dostępne komendy.
